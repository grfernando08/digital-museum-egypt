# Neferti — Digital Museum of Egypt

A responsive and interactive digital museum experience exploring the history, artifacts, timeline and exhibitions of Ancient Egypt.

## Created By

Gaviru Fernando  
Ananda College, Sri Lanka

## Technologies

HTML5  
CSS3  
JavaScript

## Features

- Interactive artifact collection
- Artifact search and filtering
- Historical timeline
- Digital exhibitions
- Responsive design
- Interactive museum elements

## Purpose

Created for the Digital Museum of Egypt Web Development Challenge.
